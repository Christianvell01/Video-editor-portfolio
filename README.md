# Fuen Belarma — GitHub upload edition

Unzip this package and upload the CONTENTS to the root of your GitHub repository. Preserve the assets/ folder. Do not upload the ZIP itself.

Enable Settings > Pages > Deploy from a branch > main > / (root). No build is needed.
